fix(publish): authenticate the previous-catalog lookup so the first catalog can publish

The catalog step looked up ghcr.io/pdp-connect/connector-catalog:latest anonymously. For a repository that does not exist yet GHCR answers the token request with 403, which lookup-manifest correctly reports as unknown, and the step refuses to proceed on unknown. The connector publish step already sends the job token for the same reason; the catalog step now does too, so a missing catalog is a clean absent and the first publish can run.
